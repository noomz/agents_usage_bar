# Plan 02.01 — JSONL Streaming Primitive

## §S — Scope

Load-bearing primitive for Plan 02.04 (Claude provider) and Phase 3 (Codex
rollout reader). Three artifacts:

1. `TranscriptReader` actor — streams JSONL via FileHandle.seek + .bytes.lines,
   returns byte-offset of last fully-parsed `\n` (Pitfall 2 crash-safety).
2. `TranscriptDirectoryScanner` — walks `~/.claude/projects/**/*.jsonl` via
   FileManager.enumerator with `.contentModificationDateKey` mtime gate.
3. `FileCacheStore` schemaVersion 1 → 2 migration — adds
   `transcripts: [String: TranscriptOffset]`, preserves Phase 1 baselines.

Task 1 (TranscriptOffset value type + lenient TranscriptRecord decoder +
5 JSONL fixtures + 9 decoder tests) landed pre-wave in commit `308d8c1`.

## §B — Backprop Notes

- B1: Swift's JSONEncoder encodes `[ProviderID: T]` as a JSON ARRAY of alternating
  key/value entries (not a JSON object) because ProviderID doesn't conform to
  `CodingKeyRepresentable`. Hand-written v1 fixtures must use this shape OR be
  generated via real round-trips. Salvage rewrote the migration test to round-trip
  through FileCacheStore + mutate the on-disk JSON.
- B2: All `CacheStore` conformances need the 3 new transcript-offset members
  (both production and test fakes). Easy to miss — `FakeCacheStore`,
  `AggFakeCacheStore`, `NoopCacheStore` all needed updates.
