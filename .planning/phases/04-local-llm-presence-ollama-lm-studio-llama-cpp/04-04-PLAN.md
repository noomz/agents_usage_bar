## Objective

Build the **Ollama provider actor** — the user-visible localhost row that probes `GET http://localhost:11434/api/ps` (running models) AND `GET /api/tags` (installed models) concurrently via `async let`, classifies the four `URLError` connection-refused codes as `.notRunning`, and folds the response into one of five D-03 row states:

- **A. Not running** — connection refused.
- **B. Idle — 0 models loaded** — server up, `/api/ps` empty, `/api/tags` non-empty.
- **B'. Idle — no models installed** — server up, both endpoints empty (degenerate; planner may collapse to state B).
- **C. `<modelName>`** — one model loaded, optional `· X.X GB VRAM` suffix.
- **D. `<firstModelName> · +N more`** — multiple models loaded (Ollama-specific).

This actor satisfies LOCAL-01 (probe `/api/ps` + `/api/tags`), LOCAL-04 (tri-state status), LOCAL-05 (connection-refused → notRunning), and LOCAL-06 (NO token count — verified by negative grep in acceptance).

**LOCAL-06 anti-feature is sacred** — every `<acceptance_criteria>` block carries a negative grep proving no token / cost field is computed or emitted.

## Context

Per CONTEXT Discretion §"One actor per runtime vs one unified `LocalProbeProvider`": three actors. `OllamaProvider` is the first.

Compositional template (RESEARCH §6.1): mirror `GeminiOAuthProvider` (Phase 3 Plan 03-06 / STATE #82) — **never throws** for transient localhost-down states. Returns a snapshot carrying `.notRunning` lastStatus + `raw["modelCount"]="0"` instead. This means:

- AggregateStore POLL-05 CircuitBreaker NEVER opens on Ollama-not-running.
- The row stays muted-gray forever, re-probed every 5-min tick.
- ROADMAP Phase 4 SC#4: "When any localhost runtime is not running … the row renders as muted 'Not running' … never blocking other providers" — satisfied by this no-throw discipline.
