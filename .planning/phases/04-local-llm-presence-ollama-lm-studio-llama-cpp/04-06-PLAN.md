## Objective

Build the **llama.cpp / llamafile provider actor** — port-gated by config (LOCAL-03 no scanning), probes `/health` (drives status) + `/v1/models` (drives model name as basename of `data[0].id`) + opportunistic `/slots` (tooltip enrichment), and surfaces the documented `"loading model"` transient state as the fifth row state E (`Running — loading model…`) per RESEARCH §5.1.

Additionally, this plan extends `AggregateStore.seedPlaceholder(...)` with an optional `placeholderMessage: String?` parameter so Plan 04-08 can render the D-04 unconfigured-llama.cpp discoverability row: `"Set [llamacpp] port in config.toml to enable"`. This carrier already lives on `ProviderState.placeholderMessage` (Phase 1 / `Domain/ProviderState.swift:28`); we simply thread it through the seedPlaceholder factory.

Satisfies LOCAL-03 (port REQUIRED, no scanning), LOCAL-04 (tri-state + state E sub-state), LOCAL-05 (connection-refused → notRunning), LOCAL-06 (no token tracking).

## Context

LlamaCpp is the **port-required** runtime (LOCAL-03 no-scanning invariant). The composition root (Plan 04-08) only instantiates `LlamaCppProvider` when `config.llamacpp.enabled && config.llamacpp.port != nil`. When unconfigured, Plan 04-08 seeds the D-04 placeholder row carrying the discoverability subtitle.

Wire shape uncertainty (RESEARCH §11 OQ-1, OQ-3): `/health` `"loading model"` exact string and llamafile-vs-mainline drift. RESEARCH §2.3 lists four documented `status` strings: `"ok"`, `"loading model"`, `"no slot available"`, `"error"`. Per OQ-3 mitigation, if status doesn't match any of those four, treat as `.ok` (best-effort) — this prevents llamafile-version-drift from flashing red rows.

State E is a SUB-STATE of `.ok` per RESEARCH §5.1 — `lastStatus = .ok(lastSuccess: now)`, BUT `raw["loadingModel"]="true"` keys the UI's transient "Running — loading model…" rendering (handled by ProviderRowView in Plan 04-07).

The plan also expands `AggregateStore.seedPlaceholder` with an optional `placeholderMessage` parameter. **CRITICAL**: this change must NOT break the Phase 3 callsites at `App/AppDependencies.swift:238-275` (openrouter / claude / codex / gemini placeholder seeds). The new parameter defaults to nil — zero blast radius on existing callers (RESEARCH §6.1 / OQ-7 disposition).

Files referenced:
- `AgentsUsageBar/Providers/Ollama/OllamaProvider.swift` (post-04-04) — actor template.
- `AgentsUsageBar/Providers/LMStudio/LMStudioProvider.swift` (post-04-05) — sequential probe chain template.
- `AgentsUsageBar/Domain/ProviderState.swift:28` — `placeholderMessage: String?` already declared (line 28).

- `AgentsUsageBar/Aggregation/AggregateStore.swift:183-194` — `seedPlaceholder(providerID:displayName:status:)` — the function being extended.

External API shape (RESEARCH §2.3, verified against llama.cpp `examples/server/README.md`):

**GET `/health`** — four documented shapes:
- `{"status":"ok","slots_idle":4,"slots_processing":0}` → `.ok` running
- `{"status":"loading model"}` → state E (`Running — loading model…`)
- `{"status":"no slot available","slots_idle":0,"slots_processing":4}` → still `.ok` running (all slots busy)
- `{"status":"error"}` → `.error(_)`

**GET `/v1/models`** — single-model:
```
{ "object": "list", "data": [{ "id": "/path/to/llama-3-8b-instruct-Q4_K_M.gguf", ... }] }
```
Trim to basename via `URL(fileURLWithPath:).lastPathComponent` (RESEARCH §2.3 — Apple URL API; do NOT split on `"/"` manually).

**GET `/slots`** — opportunistic; per-slot state array. Tooltip only.
