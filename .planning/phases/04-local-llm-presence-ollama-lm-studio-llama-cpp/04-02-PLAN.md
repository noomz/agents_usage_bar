## Objective

Extend `AppConfig` with three per-runtime configuration structs (`OllamaConfig`, `LMStudioConfig`, `LlamaCppConfig`) and teach `ConfigStore.load()` to parse the new `[ollama]`, `[lmstudio]`, `[llamacpp]` TOML sections. Implements the **config knob layer** that LOCAL-01 (Ollama enable), LOCAL-02 (LM Studio enable + port override), and LOCAL-03 (llama.cpp port REQUIRED — no scanning) all key on.

Per CONTEXT Discretion §"TOML schema additions" + §"`AppConfig` extension", precedence is env > toml > defaults (Phase 1 D-17 unchanged), with NO env override for locals (no secrets — port + enable are config knobs).

This plan lands in **Wave 1** alongside 04-01 (status foundation) and 04-03 (HTTP tier). It does NOT touch `AppDependencies.makeProduction()` — that's Plan 04-08's job.

## Context

Phase 3 STATE #87 (Plan 03-08) established the precedent: each new provider grows a `XxxConfig` struct + an `AppConfig.xxx` stored property + a `ConfigStore.load()` extraction block + a TOML section reader. Phase 4 follows the same pattern but with three structs at once.

Defaults (CONTEXT D-04 + Discretion bullets):
- `OllamaConfig.enabled = true` — well-known port 11434 (LOCAL-01 always probes the well-known port).
- `LMStudioConfig.enabled = true, port = 1234` — well-known port overridable for users running LM Studio on a non-default port.
- `LlamaCppConfig.enabled = true, port = nil` — REQUIRED in TOML to activate the row (LOCAL-03 no scanning); when nil the row stays in the D-04 placeholder state (Plan 04-06 + Plan 04-08 handle that).

Files referenced:
- `AgentsUsageBar/Config/AppConfig.swift:114-137` — `CodexConfig` precedent shape; mirror for the three new structs.
- `AgentsUsageBar/Config/AppConfig.swift:38-57` — `AppConfig.defaults` static; extend with three new defaults.
- `AgentsUsageBar/Config/ConfigStore.swift:140-181` — Codex + Gemini parse blocks; the structural twin for our new code.
- `AgentsUsageBar/Config/TomlReader.swift:14-19` — `TomlValue` cases (`.bool`, `.int`) — already supports everything we need.
