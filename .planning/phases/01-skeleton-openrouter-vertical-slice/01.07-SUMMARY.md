## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `#require` macro requires `try` in Swift Testing**
- **Found during:** Task 1 first test run (compile error)
- **Issue:** `#require(result.count == 1)` without `try` is a compile error in Swift Testing — the macro expands to a throwing expression
- **Fix:** Added `try` prefix to all `#require` calls and marked affected test functions as `throws`
- **Files modified:** `ThresholdEngineTests.swift`
- **Commit:** `5a5ee23`

**2. [Rule 2 - Missing field] `NotificationDecision` missing `displayName` and `band` fields**
- **Found during:** Task 1 read-first phase (pre-implementation check)
- **Issue:** Plan 01.02's `NotificationDecision` had only `id/title/body/providerID`. `displayName` is load-bearing for B3 coalescing body in `UNNotificationManager`; `band` is needed for FSM tracking
- **Fix:** Added both fields + updated `init` signature. No callers of the old init existed outside the stubs being overwritten
- **Files modified:** `NotificationDecision.swift`
- **Commit:** `5a5ee23`

**3. [Rule 1 - Bug] `Quota.used/limit` are `Double` not `Decimal` (body formatting)**
- **Found during:** Task 1 implementation — reading `Quota.swift`
- **Issue:** Plan spec showed body as `"$8.20 of $10.00"` using Decimal formatting, but actual `Quota` type uses `Double`
- **Fix:** Used `NumberFormatter` with `.currency` style instead of `Decimal.formatted(.currency(code:))` — produces identical output for these amounts
- **Files modified:** `ThresholdEngine.swift`
- **Commit:** `5a5ee23`
