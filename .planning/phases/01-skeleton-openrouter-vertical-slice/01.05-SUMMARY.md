## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `Task { [weak self] in await self?.performRefresh }` produces `Task<Void?, Never>`**
- **Found during:** Task 1 first build
- **Issue:** `self?.performRefresh` returns `Void?` (optional chain), incompatible with `currentRefresh: Task<Void, Never>?`
- **Fix:** Changed to `[unowned self]` capture — `AggregateStore` lifetime guaranteed by `PollScheduler`'s strong reference
- **Files modified:** `AggregateStore.swift`
- **Commit:** `442eec8`

**2. [Rule 1 - Bug] `AppDependencies.makeProduction()` used old `AggregateStore()` no-arg init**
- **Found during:** Task 1 first build
- **Issue:** Old stub init incompatible with new DI init
- **Fix:** Updated `AppDependencies` to use the full DI init; added `NoopCacheStore` fallback for `FileCacheStore()` throws
- **Files modified:** `AppDependencies.swift`, `NoopCacheStore.swift` created
- **Commit:** `442eec8`

**3. [Rule 1 - Bug] `FakeCacheStore` name collision with `OpenRouterProviderTests.swift`**
- **Found during:** Task 1 test run (redeclaration error)
- **Issue:** Both `AggregateStoreTests.swift` and `OpenRouterProviderTests.swift` defined `FakeCacheStore` in the same test module
- **Fix:** Renamed to `AggFakeCacheStore` in all Aggregation test files
- **Files modified:** `AggregateStoreTests.swift`, `PollSchedulerTests.swift`
- **Commit:** `442eec8`

**4. [Rule 1 - Bug] `ProviderCapabilities` init labels mismatch (`reportsCost:` vs `hasCost:`)**
- **Found during:** Task 1 test compilation
- **Issue:** Plan used wrong argument labels; actual Plan 01.02 type uses `hasQuota:hasCost:hasTokens:isLocal:`
- **Fix:** Corrected in both `AggregateStoreTests.swift` and `PollSchedulerTests.swift`
- **Commit:** `442eec8`

**5. [Rule 1 - Bug] `updateIntervalReplacesLoop` flaky due to 5s POLL-03 skip**
- **Found during:** Task 2 test run (intermittent failure)
- **Issue:** `updateInterval` fires a new refresh within 5s of `lastTick` → POLL-03 skips it → `count < 2`
- **Fix:** Use `VirtualClock` advancing 10s per `now()` call, ensuring each refresh bypass the 5s guard
- **Files modified:** `PollSchedulerTests.swift`
- **Commit:** `ac29fe0`

**6. [Rule 1 - Bug] `FileCacheStore` `var envelope` should be `let` (strict-concurrency `-warnings-as-errors`)**
- **Found during:** Task 1 strict-concurrency build
- **Issue:** Pre-existing `var` binding never mutated — triggers warning-as-error under `-strict-concurrency=complete`
- **Fix:** Changed to `let` in `maintainBaseline`
- **Files modified:** `FileCacheStore.swift`
- **Commit:** `442eec8`

**7. [Rule 1 - Bug] `AggregateStoreWithSpy` subclass approach incompatible with `public final class`**
- **Found during:** Task 1 acceptance criteria check (plan requires `public final class`)
- **Issue:** Original test used a subclass to override `fireThresholdNotificationsIfNeeded`; incompatible with `final`
- **Fix:** Made `AggregateStore` final as required; rewrote threshold test to use `SpyNotificationManager` injected via the real init — verifies `schedule([])` is called once per refresh (stub ThresholdEngine returns `[]`)
- **Files modified:** `AggregateStore.swift`, `AggregateStoreTests.swift`
- **Commit:** `442eec8`
