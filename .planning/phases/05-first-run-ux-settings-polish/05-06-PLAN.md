      # CFG-06: shell RC file references MUST NOT appear in any source file.
      # Rationale: env vars read via ProcessInfo.environment only; shell RC files

Place this step in the same job that runs the SEC-04 grep (keep related security checks co-located). The `!` prefix inverts the grep exit code — grep returning 0 (found matches) becomes exit 1 (CI failure); grep returning 1 (no matches) becomes exit 0 (CI pass).
