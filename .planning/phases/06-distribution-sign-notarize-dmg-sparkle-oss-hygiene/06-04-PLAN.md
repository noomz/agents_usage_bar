<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub secrets → CI runner | Live Apple/Sparkle secrets are injected into the runner; mishandling leaks credentials |
| CI → end users (appcast + DMG) | The published appcast + DMG are consumed by every installed app; tampering injects malicious updates |
| source plists → signed binary | The entitlement guard is the regression fence keeping the shipped binary least-privilege |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-08 | Information Disclosure | ASC `.p8` / Sparkle private key on runner | mitigate | `.p8` written to /tmp then `rm -f` + `trap EXIT` (Pitfall 5); Sparkle private key piped via stdin `--ed-key-file -`, NEVER written to disk (RESEARCH Anti-Patterns) |
| T-06-09 | Tampering | unsigned/forged Sparkle update injection | mitigate | `sign_update` EdDSA-signs the FINAL stapled DMG (Pitfall 4); appcast carries `sparkle:edSignature` verified against the pinned `SUPublicEDKey`; appcast hosted on gh-pages over HTTPS |
| T-06-10 | Elevation of Privilege | entitlement creep regressions | mitigate | `entitlements-guard` CI job fails the build if forbidden entitlements appear or REL-08/09 invariants break — runs on every push without Apple creds |
| T-06-11 | Tampering | wrong action version (supply chain) | mitigate | `import-codesign-certs@v7` (current, security-patched; NOT the stale v3 in CLAUDE.md — Pitfall 7); all action versions pinned per RESEARCH verified pins |
| T-06-12 | Spoofing | notarization bypass via app-specific password / altool | mitigate | ASC API key (`.p8`) only; workflow contains no `altool` and no app-specific password (acceptance grep) |
| T-06-SC | Tampering | npm/pip/cargo installs | accept | No package-manager installs; create-dmg + Sparkle downloaded from pinned official GitHub release tarballs (RESEARCH Package Legitimacy Audit: both Approved); appcast helper is stdlib-only Python (no pip) |
