<objective>
Implement SEC-03: when the app creates `~/.config/agents-usage-bar/config.toml`, create it with POSIX mode `0o600`; on every config load, warn via `os.Logger` (never crash) if the file is found world- or group-readable (`mode & 0o077 != 0`).

Purpose: Config can hold provider API keys. A world-readable config leaks credentials to other local users. SEC-03 closes that exposure and makes the warning observable.
Output: `ConfigStore` gains `ensureConfigFile(contents:)` (0600 creation) + `checkAndWarnPermissions()` (startup warning), wired into `load()`; a new Swift Testing file proves both behaviors. This is the ONLY Swift code change in Phase 6 (D-09).
</objective>
